# DiplomaturaCoder
# Sitio Web - Occhiwebs

Este repositorio contiene el desarrollo de un sitio web estático multipágina implementando HTML5 y CSS3, basado en los contenidos y la práctica de la diplomatura de desarrollo web de Coderhouse. 

## Descripción del Proyecto
El proyecto fue realizado integrando los conocimientos fundamentales adquiridos en la diplomatura (maquetación semántica, modelos de caja, selectores y organización modular) junto con conceptos y técnicas complementarias provenientes de la formación en React de Coderhouse.

## Tecnologías Utilizadas
* **HTML5**: Estructura semántica de las páginas (`header`, `nav`, `main`, `section`, `article`, `footer`).
* **CSS3**: Estilización visual, tipografías externas y organización con clases selectas.
* **Control de Versiones**: Git / GitHub.
